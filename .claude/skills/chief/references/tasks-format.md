# Format of tasks.md and decisions.md

Task lines:

```
- [ ] Task  [due:: 2026-10-07]  [owner:: Ravi]  [prio:: high]
- [x] Task  [done:: 2026-10-04]
```

Sections in this order: `## Doing`, `## This week`, `## Next week`, `## Backlog`, `## Done`. Fields are optional; an empty owner means the user. `prio` is `high`, `medium` or `low`.

`decisions.md`: `## Scope`, `## Working agreements`, `## Decision log` (table `Date | Decision | Source`).
